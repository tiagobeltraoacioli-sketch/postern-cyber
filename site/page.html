Coverage

What an enterprise endpoint platform does, in a codebase you can read.

Sensor

Kernel-level telemetry

On Linux the kernel pushes every program start to the sensor, with parent, user and SHA-256. Connections, listening ports and logons on every platform.

Detect

Behavioral detections

47 rules for Linux, macOS and Windows: reverse shells, web shells, LSASS dumps, malicious documents, persistence, miners, tunnelling, log tampering. Write your own in YAML.

Prevent

Block before execution

On Linux the kernel waits for the sensor's verdict. A binary on your hash block list, or under a blocked path, never starts, even renamed.

Recover

Ransomware rollback

Versioned copies of the directories you protect, canary files checked every five seconds, and one action that restores the last good snapshot.

Correlate

Incident storyline

Alerts on one host inside a 30-minute window join a single incident, so an intrusion reads as one case instead of ten pages.

Respond

Containment

Kill a process, quarantine a file, isolate a host from the network with nftables. Manual by default; automatic per host in protect mode.

Integrity

File integrity monitoring

Account databases, sudoers, SSH keys, cron, systemd units and the dynamic linker preload are hashed and watched for change.

Intel

Indicator matching

Load file hashes and addresses. A running process or connection that matches raises a high-severity alert.

Exposure

CVE matching and posture

Installed packages are matched against the public vulnerability database on your own server. Plus SSH, firewall, updates, disk encryption and Defender checks.

XDR

Third-party ingestion

Post firewall, cloud or identity logs to one API endpoint. They run through the same detections and land in the same incidents.

Govern

SSO, roles and audit

Sign in through your identity provider with OpenID Connect. Viewer, analyst and admin roles. Every action is recorded with who asked for it.

AI analyst

Claude Mythos 5.2 reads the case file. You sign the order.

Paste an Anthropic API key in Settings and the console gains an analyst. Mythos 5.2 is available to verified organizations; any other Claude model id works in the same field.

Triage an incident

One click sends the alerts and the surrounding telemetry. Back comes a verdict, a confidence figure, a narrative that cites event ids, ATT&CK techniques and a list of actions to approve.

Hunt in plain language

Ask "did anything on the database hosts open a new listener this week?" The model queries your event store with read-only tools and shows every query it ran.

Draft a detection

Describe a behaviour. You get a validated rule, the reasoning behind it and the false positives to expect. It goes live only when you save it.

Built for an adversarial input

Command lines and file names are written by the attacker. The integration assumes they will try to talk to the model.

  • Telemetry reaches the model as tagged data, with standing instructions to treat it as evidence and never as a request.
  • The model has no tool that changes anything. It recommends; an operator approves each action in the console.
  • The console escapes every value it renders, so a hostile string cannot run script in the analyst's browser.
  • If a request is declined by a safety classifier, the server says so plainly and can re-run it on Anthropic's recommended fallback model.
Deploy

One server, one sensor per host, one key.

Start the server

A single binary with an embedded database and console. It writes an admin token on first start.

postern-server \
  --listen 127.0.0.1:8460 \
  --data-dir /var/lib/postern

Enroll a sensor

Observe-only unless you grant response capabilities on that host.

postern-sensor \
  --server https://console.example.com \
  --enroll-token pce_… \
  --response kill,isolate,prevent,rollback \
  --protect /srv/data

Connect the analyst

Set the key in the console, or keep it out of the database entirely.

export ANTHROPIC_API_KEY=sk-ant-…
export POSTERN_AI_MODEL=claude-mythos-5-2
